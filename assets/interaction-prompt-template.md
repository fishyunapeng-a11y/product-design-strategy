# 交互原型生成 Prompt 模板

## 使用说明

此模板用于生成「可生成交互草稿的prompt」部分。根据目标工具选择对应的模板版本。

## 版本一：通用版（适用于各类AI图像/设计生成器）

适用于：Midjourney、DALL-E、Stable Diffusion、通用LLM等

```markdown
# [产品名称] 交互原型设计

## 设计要求

请根据以下信息生成[产品名称]的交互原型设计，输出格式为[线框图/高保真原型/交互流程图]。

[在此处插入「通用信息模板」的内容]

## 输出要求

1. **页面原型**：为每个页面生成独立的设计稿
2. **交互说明**：用文字描述每个页面的交互逻辑
3. **状态覆盖**：包含正常态、空态、加载态、错误态
4. **动效描述**：标注关键动效（如页面转场、按钮反馈）

## 风格要求

- 整体风格：[简约/现代/科技感/温馨]
- 配色方向：[主色调、辅助色]
- 细节处理：[圆角、阴影、间距等]
```

## 版本二：Figma Make 专用

适用于：Figma AI 功能、Figma Make 插件

```markdown
# [产品名称] Figma Make Prompt

## 任务

使用 Figma Make 生成 [产品名称] 的交互原型，要求生成可直接导入 Figma 的组件结构。

[在此处插入「通用信息模板」的内容]

## Figma 组件要求

### 组件层级结构

```
Frame (页面名称)
├── Header (导航栏)
│   ├── Back Button
│   ├── Title
│   └── Action Button
├── Content Area (内容区)
│   ├── Component A
│   ├── Component B
│   └── ...
└── Bottom (底部区域)
```

### 组件命名规范

- 使用清晰的英文命名
- 遵循 Figma 命名约定
- 相关组件使用统一前缀

### 响应式要求

- 移动端：390px 宽度（iPhone 标准）
- 使用 Auto Layout 实现自适应
- 组件使用 Instance 便于复用

## 设计规范

- 使用 [设计系统名称] 或默认 Material Design
- 颜色使用变量定义
- 字体使用系统字体栈
- 间距遵循 4px 基准
```

## 版本四：Stitch / Galileo 专用

适用于：Stitch AI、Galileo AI 等设计到代码工具

```markdown
# [产品名称] Stitch/Galileo Prompt

## 生成指令

请使用 Stitch/Galileo 将以下设计需求转换为可编辑的设计稿。

[在此处插入「通用信息模板」的内容]

## Stitch 配置

### 设计稿设置

- **画布尺寸**：[宽度] x [高度] px
- **安全区域**：考虑刘海屏和底部导航栏
- **方向**：竖屏/横屏

### 组件库选择

- 优先使用 [iOS Human Interface Guidelines / Material Design] 组件
- 自定义组件需提供变体设计
- 表单组件需包含 placeholder 和验证状态

### 交互状态

为每个可交互元素生成以下状态：
1. Default（默认）
2. Hover/Pressed（悬停/按压）
3. Active（激活）
4. Disabled（禁用）
5. Loading（加载中）

## 输出格式

- 格式：Figma 设计稿 / Sketch 文件
- 命名：[产品名称]_Prototype
- 组织：按页面分组，使用 Frame 嵌套
```

## 填写指引

### 如何描述功能
- 使用动词开头：「查看订单」「提交表单」「筛选结果」
- 说明触发条件：「点击按钮后」「进入页面时」「数据加载完成后」

### 如何描述组件状态
- 默认：用户未操作时的外观
- 悬停/按压：手指接近时的微交互
- 选中：被选中时的视觉反馈
- 禁用：不可操作时的外观

### 如何描述动效
- 使用动词：滑入、淡入、缩放、弹出
- 说明时长：快速（100ms）、正常（300ms）、缓慢（500ms）
- 说明缓动：线性、ease-in、ease-out、ease-in-out
