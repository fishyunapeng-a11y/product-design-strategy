# 信息架构模式参考

## 常见架构模式

### 1. 层级结构 (Hierarchical)

**适用场景**：电商、内容平台、企业官网

**特点**：
- 顶层分类 → 子分类 → 具体内容
- 用户通过逐级下钻找到目标

**示例**：
```
首页
├── 产品
│   ├── 电子产品
│   │   ├── 手机
│   │   └── 笔记本
│   └── 家用电器
├── 关于我们
└── 联系我们
```

### 2. 平铺结构 (Flat)

**适用场景**：功能明确的工具类应用、简单网站

**特点**：
- 所有主要功能入口平级展示
- 减少点击层级

**示例**：
```
[首页] [订单] [设置] [帮助] [我的]
```

### 3. 时间线结构 (Timeline)

**适用场景**：社交动态、消息列表、任务管理

**特点**：
- 按时间顺序排列内容
- 支持倒序/正序

**示例**：
```
最新 →
[10:30] 张三评论了你的帖子
[09:15] 李四关注了你
[08:00] 系统通知
```

### 4. 搜索/筛选结构

**适用场景**：搜索结果页、筛选器、内容发现

**特点**：
- 提供多维度筛选条件
- 支持组合查询

**示例**：
```
搜索框 [地点筛选] [价格筛选] [排序方式]
```

### 5. 用户旅程结构

**适用场景**：多步骤流程、表单填写、任务完成

**特点**：
- 围绕用户完成目标的步骤组织
- 提供进度反馈

**示例**：
```
步骤1: 填写信息 → 步骤2: 选择服务 → 步骤3: 确认订单 → 步骤4: 支付
```

## 实体建模指南

### 核心实体类型

| 实体类型 | 描述 | 常见属性 |
|---------|------|---------|
| 用户 | 系统使用者 | ID、昵称、头像、角色 |
| 内容 | 可消费的信息 | 标题、描述、分类、标签 |
| 任务 | 需要完成的操作 | 状态、优先级、截止时间 |
| 订单 | 交易记录 | 金额、状态、时间 |
| 设置 | 用户偏好配置 | 主题、语言、通知偏好 |

### 实体关系类型

- **一对一 (1:1)**：用户与个人资料
- **一对多 (1:N)**：用户与订单
- **多对多 (N:M)**：用户与关注列表
